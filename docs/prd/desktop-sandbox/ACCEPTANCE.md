# 安全规则验收用例

本清单对应已明确的授权、秘密交付与文件回写规则。原型可验证界面状态和操作路径；涉及真实进程、凭据、宿主文件和并发的断言须在实现后执行，不能用原型演示替代。

## 授权

| 编号 | 场景与操作 | 通过条件 |
|---|---|---|
| AUTH-01 | 未申请或显式拒绝的低风险能力被请求，例如进程派生。 | 不执行；风险低不能产生授权或覆盖拒绝；记录拒绝结果。 |
| AUTH-02 | 审查时只选沙箱副本写入，不选付费账号调用或部分其它能力，然后启动。 | 允许按获准子集启动；每个未选项保持拒绝，推荐配置与运行时策略都不能恢复它。 |
| AUTH-03 | 对被拒请求申请补授，分别执行取消、关窗、超时和确认。 | 前三者保持拒绝；确认必须经过完整审查并产生有效授权/记录后才能生效。旧拒绝只能由明确的新决定变更，不能由风险计算覆盖。 |

## 秘密

| 编号 | 场景与操作 | 通过条件 |
|---|---|---|
| SECRET-01 | 使用已配置 HTTP 认证头代理路径。 | 密钥由宿主代理使用；原始凭据不进入 guest。界面说明仅针对该模式；只向本次授权目标注入，日志不输出明文。 |
| SECRET-02 | 选择引用模式，分别不勾风险确认、勾选并完成审批。 | 未确认不交付；明确说明目标进程将获得明文且可以复制/外传。批准记录绑定运行、目标进程启动标识、秘密引用和实际适配器。 |
| SECRET-03 | 目标程序原生支持匿名 fd 或通过经验证适配器读取；另测未知适配器、未验证版本、仅接受 env/argv/磁盘文件的程序。 | 仅匹配支持矩阵的目标可交付。其余阻断并给出不支持原因，不自动降级，不把模拟适配器标作真实支持。 |
| SECRET-04 | 通过一次性匿名 pipe/fd 交付；尝试交付给错误运行、错误进程或未获准子进程，并触发消费结束/退出。 | 身份不匹配拒绝；仅选定目标继承所需描述符，消费后关闭。受控缓冲区清理、禁转储等措施可验证，但不宣称能约束第三方程序主动复制后的全部内存。 |
| SECRET-05 | 交付前授权过期/撤销，以及引用已交付后撤销。 | 前者不交付且不继续代理认证；后者终止相关运行、阻止后续交付并提示需要的凭据轮换，不声称可收回已复制的秘密。 |

## 文件回写

| 编号 | 场景与操作 | 通过条件 |
|---|---|---|
| WRITE-01 | 按默认读写配置启动，在沙箱修改、增加、删除文件。 | 所有改动发生在沙箱副本；真实宿主文件保持不变。普通读写路径不能切换为未经确认的直接写宿主。 |
| WRITE-02 | 宿主未变化时预览并确认选定改动。 | 显示选定路径及改动，确认绑定本次差异摘要与宿主版本；提交前重新校验。只回写本次明确选择的内容，成功结果与实际写入对应。 |
| WRITE-03 | 沙箱运行后宿主文件发生变化，再请求回写。 | 正常回写被阻断，显示基线、当前宿主、沙箱副本三方差异；默认不覆盖。用户可以取消、处理冲突后重新预览、或明确选择覆盖。 |
| WRITE-04 | 用户已查看差异并确认，执行前再次修改宿主；对普通回写和明确覆盖分别执行。 | 旧确认失效；不使用旧版本批准继续写入。返回宿主已变化，刷新差异并要求重新确认；覆盖许可不是忽略未来变化的通行证。 |
| WRITE-05 | 在预览、冲突、覆盖确认各步骤取消/关窗；再使用旧确认或重复发送已消费确认。 | 取消不写入；已取消或失效的确认不能使用。已完成请求重复提交不再次执行覆盖，返回原结果或明确拒绝。 |
| WRITE-06 | 对删除、重命名、二进制文件、符号链接/父目录替换、禁止路径以及多文件批次进行预览和提交。 | 操作类型与影响范围明确；没有文本差异的二进制必须显示版本/大小等信息；链接逃逸和禁止路径不能通过覆盖确认绕过。执行前任一选定路径冲突，整个批次先阻断。 |
| WRITE-07 | 写入过程中发生 I/O 错误、外部并发修改或无法可靠验证版本。 | 失败关闭，不静默覆盖未授权变化；准确区分已写入与未写入文件，不宣称批次全成功，也不自动重放全批次。保留未应用的沙箱副本供再次预览处理。 |

实现验收还需验证：重命名两端和父目录的身份/版本、路径安全解析与实际写入之间的竞态、对外部不遵守应用锁的写入者能否可靠检测。仅有一次 hash 检查或应用内互斥锁不能作为此项通过依据；无法保证时应阻断受影响回写。

## 关联回归

- 运行前审查、补授、秘密模式切换、运行面板及首次引导的措辞保持一致。
- 模式切换后，旧能力批准或引用风险确认不能意外沿用到新服务/新适配器。
- 拒绝、冲突、取消与过期结果须能与对应运行和批准记录关联。
- 副本没有回写前退出时，提示处理未应用改动；不得以未确认退出隐式回写宿主。
