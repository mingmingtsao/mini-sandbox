# 产品工程里程碑 v2

本页定义模块交付、依赖与验收要求。具体人员安排和开发工具不属于此产品规格。

| 编号 | 模块与交付 | 依赖 | 基础验收 |
|---|---|---|---|
| V2-00 | Mac 环境、镜像/构建基线与已有产品结构核实 | — | E01 |
| V2-01 | RunGrant/PendingAction/SecurityEvent 与策略单元 fixture | V2-00 | S12、S14、S15、S23 |
| V2-02 | 打包 App、无通用网卡 VM、vsock 通信 | V2-01 | E01、E02、S03、S04、S24 |
| V2-03 | 首个 Agent 的宿主模型路由、流式与取消 | V2-02、V2-05 | S01、S06、S07、S25 |
| V2-04 | 导入项目副本、Diff、新目录导出 | V2-02 | S02、S20、S21 |
| V2-05 | 原生权限审批、撤权、可信事件与生命周期 | V2-01、V2-02 | S13、S16、S17、S18、S22、S23、S26 |
| V2-06 | 真实 HTTP MCP 和资源/动作级授权 | V2-03、V2-05 | E05、S08、S09、S10、S11、S19 |
| V2-07 | OAuth 和 stdio 连接器适配 | V2-06 | E04、E06、E07、E08、S05、S27 |
| V2-08 | 三 Agent 完整兼容测试 | V2-03、V2-04、V2-06 | E03、E04 |
| V2-09 | VM、网络、MCP、文件与生命周期攻击回归 | V2-04～V2-08 | S01～S27 |
| V2-10 | 真人易用性验收与打包交付 | V2-09 | U01、R01 |

**关键路径：** VM 可启动 → 宿主凭据代理可用 → 一个 Agent 完成真实任务 → MCP 资源级授权可验证 → 三 Agent 兼容与安全回归。不得为赶进度改为宿主裸跑、默认开放网络或把长期凭据注入 guest。
