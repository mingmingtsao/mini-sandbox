## 预览

下载此目录，直接用浏览器打开 [index.html](index.html)，无需安装依赖。

也可在本目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/`。停止服务使用 `Ctrl+C`。

## 演示路径

- **部分授权**：运行程序 → 只勾选副本文件权限 → 启动；未选能力保持拒绝。
- **密钥边界**：账号与密钥 → 代理/引用切换；引用需明确风险确认，待验证适配器阻断。点击“模拟适配通过”仅演示通过状态。
- **确认回写**：工作台 → 预览回写 → 选文件 → 确认差异 → 执行回写。
- **冲突处理**：模拟宿主再次修改 → 重新获取差异 → 取消、编辑处理结果后重预览，或明确确认覆盖所选文件。
- **确认失效**：确认差异后再次模拟宿主修改 → 执行回写；旧确认失效，必须重新获取差异并确认。

所有文件和凭据操作均为本地内存模拟，不读取真实密钥，不修改真实宿主文件。刷新页面重置演示状态。
